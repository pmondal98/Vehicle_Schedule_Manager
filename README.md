# Vehicle Schedule Manager

A web application to manage vehicle schedules, built using HTML, CSS, JavaScript.

## Features

### User Authentication

- Secure user authentication using Firebase Authentication
- Users can sign up, log in, and reset their passwords
- Authentication state is persisted across page reloads

### Schedule Management

- Create new schedules with vehicle number, date range, and notes
- View existing schedules in a grid layout
- Delete schedules with a single click
- Schedules are stored in Firestore and synced across all users

### Search Functionality

- Search for schedules by vehicle number using a dynamic search bar
- Search results are updated in real-time as you type
- Search is case-insensitive and matches partial vehicle numbers

### Responsive Design

- Optimized for mobile and desktop devices
- Responsive layout adapts to different screen sizes and orientations
- Touch-friendly interface for mobile devices

## Usage

1. Sign up or log in to access the application
2. Add new schedules using the form
3. View and manage existing schedules
4. Search for schedules by vehicle number using the search bar
